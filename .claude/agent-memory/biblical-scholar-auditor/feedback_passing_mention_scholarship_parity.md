name: Passing-mention scholarship parity rule
description: Cross-citation parity rule: scholars named in commentary prose require a scholarship entry, even passing mentions, when convergence passes target this
type: feedback
---

When a late audit pass (typically pass 4+) targets "cross-citation parity," every scholar named in `commentary` should have a corresponding entry in `scholarship`. Pass 3 may have flagged but not fixed these (e.g., Walton/Matthews/Chavalas IVP Bible Background, Brueggemann countertestimony framework, Younger NIVAC, Childs OTL Isaiah, Amit Brill Judges, Zakovitch ZAW).

**Why:** The scholarship field functions as a verifiable footnote for the prose. Named scholars without scholarship entries create unverifiable claims — readers can't check the named scholar's actual position. Pass-3 has historically tolerated these as "passing mentions"; later passes correct them when the target shifts to publication-grade citation completeness.

**How to apply:** When the user explicitly asks to fix cross-citation parity in a late pass, add scholarship entries for ALL named scholars in commentary, even when only mentioned in passing. Keil-Delitzsch is the only consistent exception (generic 19th-century shorthand). Wellhausen, Henry Morris, and I. Howard Marshall — initially treated as "foils to leave out" — should actually be added when explicitly named with a specific position (e.g., "Bruce/Marshall line," "Modern apologists from Henry Morris forward," "going back to Wellhausen"). Pass 5 of batch_11 specifically required adding Marshall, Hill (NIVAC Chronicles), Archer, Morris, and Wellhausen entries that earlier passes had missed.

**Reliable passing-mention citations to use:**
- Walton/Matthews/Chavalas IVP Bible Background OT — InterVarsity, 2000 (1st ed)
- Childs Isaiah — OTL, Westminster John Knox, 2001
- Amit Judges — *The Book of Judges: The Art of Editing*, Brill (Biblical Interpretation 38), 1999
- Zakovitch "Sisseras Tod" — *ZAW* 93 (1981): 364-374
- Longman Psalms TOTC — IVP, 2014 (vol. 15-16)
- Younger NIVAC Judges/Ruth — Zondervan, 2002 (typically pp. 137-160 for Judg 4-5)
- Marshall, I. Howard — *Acts of the Apostles*, TNTC 5, IVP, 1980 (for any "Bruce/Marshall" reference on Acts)
- Hill, Andrew E. — *1 and 2 Chronicles*, NIVAC, Zondervan, 2003 (for Chronicles harmonization)
- Morris, Henry M. — *The Biblical Basis for Modern Science*, Baker, 1984 (for Job 26:7 / young-earth apologetic on cosmology)
- Wellhausen, Julius — *Prolegomena to the History of Israel*, trans. Black/Menzies, Edinburgh: A. & C. Black, 1885 (for source-critical historical reference)
- Archer, Gleason L. — *Encyclopedia of Bible Difficulties*, Zondervan, 1982 (default apologetic harmonization foil)
