The "passing-mention scholarship parity" rule (every named scholar gets a scholarship entry) is a calibrated heuristic, not an absolute. Apply when:
- The named scholar is the primary harmonization authority being engaged AND the entry's scholarship roster does not contain ANY apologist-side reference at all.
- The named scholar is paired with another scholar already in scholarship, creating asymmetric parity.

DO NOT apply when:
- The entry already has 5+ verified citations including at least one apologist reference (Archer, Blomberg, etc.).
- Adding the scholarship entry would require specific page ranges that cannot be confidently verified.
- The passing mention is part of a generic "Apologists like X and Y" formula without engaging the specific argument.

**Why:** Adding speculative page ranges introduces new error vectors. A clean batch that loses its zero-trajectory due to manufactured parity adds with unverifiable pagination is worse than a clean batch with a few passing mentions left as-is. The parity rule is meant to surface real underrepresentation, not enforce ceremonial citation completeness.

**How to apply:** During late audit passes, when tempted to add a Carson/Moo/Walton/Marshall/Bock entry for a passing mention, first verify (a) whether the entry already has an apologist reference, and (b) whether the specific page range can be confirmed via search. If either check fails, leave the passing mention unaddressed.

Source incident: batch_30 pass 16 — attempted to add Carson (Matt 6:7), Walton (levirate), Moo (Romans 13), Marshall+Bock (Acts 1) entries with speculative page ranges. Reverted after recognizing the entries already had Archer/Blomberg-style apologist coverage and the new pages were unverified guesses.
