- **Self-crossref reconciliation**: a Gill note naming a verse "for the reconciliation of these Scriptures" self-confirms pd_work treats that pair (id 185). Generalizes: when a K&D/Gill/Clarke reconcile note rebuts a named critic BY NAME, that critic's engagement is self-confirmed by the note (see the Hupfeld/id-106 case in [[sonnet-named-skeptic-fabrication]]).
- **1 Tim 3:2 office qualification** (id 27): a pd_work claiming Gill reads "husband of one wife" as banning polygamy for ALL believers inverts Gill — he reads it as an OFFICE qualification for elders/deacons specifically → deeper_learning flag.
- **Verse-ref off-by-N pattern**: recurring across many ids (160/128/342/348/394/423/416/420/442, cf. 351, 446 [1 Tim 2:5→6]) — Gill's excerpt sometimes belongs to an adjacent verse from the one labeled; always verify the opening clause against the KJV verse text before trusting the verse_ref label.
- **Deut 3 verse offset**: Gill's "wroth for your sakes"/Meribah harmonization is on Deut 3:26, not 3:25 — harmonization id 160 mislabeled the verse_ref.
- **Neh 7:6 copyists=names-only**: a reused Gill preface note scopes "copying slips" to NAME variants only, never NUMBER gaps — watch for this note being reused/stretched to cover a numeric discrepancy it doesn't address (id 333).
