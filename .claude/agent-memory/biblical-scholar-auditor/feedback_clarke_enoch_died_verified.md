id 559 "Did Enoch die?" (Heb 11:13 "these all died" vs Heb 11:5/Gen 5:24 Enoch not seeing death)
audited all-clean, single reconcile excerpt sample.

- Adam Clarke's Commentary on Hebrews 11:13 genuinely restricts "these all died" to
  "Abraham, Sarah, Isaac, and Jacob" (the patriarch cluster of vv.8-12), implicitly
  excluding Enoch/Abel/Noah — verbatim-confirmed against StudyLight.org's Clarke's
  Commentary transcription. This is a real, on-topic harmonization, not a fabrication.
- Discrepancy pole named_skeptic "Steve Wells" / SAB "Did Enoch die?" page
  (skepticsannotatedbible.com/contra/enoch_die.html) verified real and on-topic: SAB
  literally brackets "[Abel, Enoch, Noah, Abraham, Sarah] all died" against Heb 11:5,
  matching the connective's description exactly. Consistent with prior Wells/SAB
  real-skeptic precedent ([[feedback_sonnet_named_skeptic_fabrication]]).
- deeper_learning pd_work (Clarke on Heb 11:13, same work as the reconcile excerpt)
  and link (gotquestions.org/died-in-faith.html) both verified real and on-topic —
  the gotquestions page independently argues Enoch's "died in faith" inclusion is a
  spiritual-category reading, matching the link note's paraphrase closely.

**Why:** confirms the Clarke-restricts-referent harmonization pattern (also seen
elsewhere in this project, cf. [[feedback_clarke_1832_codebook_year]]) is a
legitimate, recurring, verifiable move — not an AI-fabricated gloss — when the
excerpt genuinely narrows the antecedent of a list-summarizing verse.

**How to apply:** when a reconcile excerpt narrows a "these all X" type verse to
exclude the contested figure, verify the excerpt against a primary transcription
(StudyLight, biblehub, archive.org) before trusting it; don't reflexively flag
referent-narrowing as strawmanning — it is a standard, real exegetical harmonization
technique when actually present in the source note.
