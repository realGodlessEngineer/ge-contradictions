the pages"). He previously used the pseudonym "Chris Thiefe" after "credible
violent threats and an arson attack on his house" (confirmed via web search
cross-referencing RationalWiki's EvilBible.com entry). Site launched 2003.

**Why:** id 605 (Genesis 9:2 "fear of every beast" vs. Proverbs 30:30 fearless
lion) named Baba as the `named_skeptic` on the discrepancy pole, with the
connective describing him as the source of the exact question. Verified via
BibViz/philb61 mirror (`is-every-animal-afraid-of-man-evil-bible.html`, which
cites its original source as `evilbible.com/Biblical%20Contradictions.htm`) that
this exact Gen 9:2/Prov 30:30 pairing is genuinely an EvilBible.com list entry,
and that Baba is genuinely the site's author — not an invented critic.

**How to apply:** When a row's `question`/source-tagging traces to EvilBible.com
(this project's third scrape source alongside SAB and Infidels — see
[[project_contradictions_db]]) and the discrepancy pole names "Christopher A.
Baba" or "EvilBible.com" as the skeptic, this is a legitimate, real,
fairly-engaged attribution (parallel to the already-established pattern of
citing Wells/SAB or the site's own editor as the named skeptic for
site-sourced questions — see the Wells/SAB entries in
[[feedback_sonnet_named_skeptic_fabrication]]). Don't flag `not_real` on this
attribution alone; still check the connective doesn't overclaim/misquote what
