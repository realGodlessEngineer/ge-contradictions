McKinsey's *Encyclopedia of Biblical Errancy* (Prometheus, 1995) census/numbers
material is squarely his documented wheelhouse. Confirmed real for the Ezra
2 / Nehemiah 7 clan-total gap cluster: ids 320, 329, 344, 346, 319 all verified
via `tektonics.org/af/eznehnumb.php` ("Ezra 2 vs Nehemiah 7"), which opens by
quoting McKinsey directly: "out of approximately thirty-five subclans listed
over half of the numbers are in disagreement" — near-verbatim to these rows'
connectives. Likely siblings 333/334/338/350 etc. share this same attribution.

**Self-correction lesson (id 319):** a first pass that only checks the general
`tektonics.org/af/ebestart.php` index or generic WebSearch queries will miss
these — tektonics has topic-specific rebuttal pages the index alone doesn't
surface. Before defaulting ANY McKinsey citation to not_real: (1) search
`tektonics.org/af/<topic-slug>.php` guesses or `site:tektonics.org <topic>`,
(2) check sibling memory/prior audits for the same cluster, (3) only flag
not_real after that dedicated-page search comes up empty.

**Paired Haley lesson:** for a Haley 1874 (`examinationof00hale`) pd_work quote
on the same rows, ALWAYS try the archive.org search-inside API (2-3 short
exact-phrase queries) before flagging unconfirmable — see
[[feedback_archive_org_fulltext_search_technique]]. It recovered verbatim
confirmations (p.396 "copyists' blunders" / p.397 "twenty in number... explained
in the same manner") that djvu.txt/HathiTrust/Google Books all failed to
surface. Note the leaf-vs-printed-page offset (~16 for this item) documented in
that technique file.
