---
name: Translator name intra-batch consistency
description: Same translator should appear with consistent form (middle initial) across all citations in a batch
type: feedback
---

When the same translator appears across multiple citations within a batch, the form should be consistent. Specifically, "James E. Crouch" (with middle initial) is the standard formal form for the Hermeneia Luz Matthew and Bovon Luke translator.

**Why:** Batch_19 pass 3 entry 376 had "Translated by James Crouch" (no middle initial) while entries 377 and 380 had "Translated by James E. Crouch." Within the same batch, the same translator should have a consistent name form. This is a citation-style intra-batch consistency issue analogous to pass-2's Davies-Allison author-order class.

**How to apply:** When auditing late passes, grep for "Translated by" lines across the batch and ensure each translator's name form is identical across all entries. Standard formal Hermeneia translator names: James E. Crouch (Luz Matthew, Bovon Luke 3), Margaret Kohl (Wolff Obadiah-Jonah, Baltzer Deutero-Isaiah), Christine M. Thomas (Bovon Luke 1), Ronald E. Clements (Zimmerli Ezekiel 1).
