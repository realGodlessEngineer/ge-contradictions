David Friedrich Strauss's *The Life of Jesus Critically Examined* (German 1835-36;
George Eliot's English translation 1846) contains §104, "Jesus Curses a Barren
Fig-Tree" (Part II, Ch. IX), which directly addresses the Matthew 21:19-20 vs.
Mark 11:13-14, 20-21 fig-tree timing tension (id 451). Verified verbatim via
archive.org djvu.txt of `lifeofjesuscriti00straiala` (server ia601902.us.archive.org,
dir /33/items/lifeofjesuscriti00straiala — see [[feedback_archive_org_fulltext_search_technique]]
for the general technique; this time plain djvu.txt grep sufficed, no search-inside
API needed).

Strauss's actual argument: taken alone, Matthew's flat "immediately"
(παραχρῆμα) "would be difficult... to carry out a natural explanation," and
Paulus's harmonizing move — reading Mark's overnight gap into Matthew's wording
— "rests only on an unwarranted transference of Mark's particulars into the
narrative of Matthew." This is an exact match to the pole connective attributed
to him in id 451 ("Matthew's flat 'immediately' cannot honestly be harmonized by
importing Mark's overnight gap into wording Matthew never wrote that way") — not
a strawman, a faithful paraphrase of a real textual-critical objection.
