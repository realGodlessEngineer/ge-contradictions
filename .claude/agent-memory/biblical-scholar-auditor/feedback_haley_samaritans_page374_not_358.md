id 506 ("Did the Samaritans receive Jesus?"): both `discrepancy.skeptic.work` and
`deeper_learning.defense.pd_work.resource` cited John W. Haley, *An Examination
of the Alleged Discrepancies of the Bible* (1874), "p. 358" for the Baur/Bleek
exchange on Luke 9:52-53 vs. John 4:39-40. Verified via archive.org
fulltext-search-inside (`examinationof00hale`, server `ia800706.us.archive.org`,
dir `/16/items/examinationof00hale`) that the heading "Samaritans received not
Jesus. Treated him hospitably." and the actual Baur/Bleek text ("Baur finds a
'discrepancy' here; but Bleek replies that ... refers to a city in the land of
Samaria") are both indexed on **p. 374**. Page 358 is a *different* topic:
Haley's own back-of-book index (p. 488) has a separate line "Samaritans,
inhospitality, 358" — that entry is the ethical-discrepancy discussion of the
disciples' fire-from-heaven request (Luke 9:54), not the reception-of-Jesus
harmonization. The two "Samaritan" discussions sit ~16 pages apart in Haley
and are easy to conflate.

**Why:** the content description attached to both citations (heading text,
Bleek's reply, "city in the land of Samaria") is accurate to Haley's real
argument — only the page number drifted, most likely by pulling the wrong
line from Haley's own index (which lists two distinct "Samaritans..." entries
close together on p. 488) rather than the body text.

**How to apply:** for any Haley 1874 citation, verify with archive.org
fulltext-search-inside using distinctive quoted phrases from the note field
(not just the topic name) — see [[feedback_archive_org_fulltext_search_technique]].
Do not trust a page number just because the topic label sounds right; Haley's
book has multiple entries under similar "Samaritans..." headings at different
pages. This is a `deeper_learning=flag` (pd_work citation wrong), not a
`named_skeptic=not_real`/`strawman` (Baur/Bleek content itself is real and
fairly reported) — keep the two guardrails distinct when only the locator,
not the substance, is wrong.
