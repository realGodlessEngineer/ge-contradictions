D. F. Strauss recurs often as the discrepancy-pole named skeptic (his method
systematically pairs Synoptic/Johannine divergences). Citation convention:
*The Life of Jesus Critically Examined* (German *Das Leben Jesu*, 1835-36; Eng.
tr. George Eliot, 1846 — both year forms acceptable). Primary text: Project
Gutenberg ebook 64037; archive.org item `lifeofjesuscriti00straiala` (1902
1-vol Eliot tr., djvu.txt + fulltext search-inside both usable — see
[[feedback_archive_org_fulltext_search_technique]]).

**Five verified-real, fairly-represented engagements (named_skeptic=ok, all
clean):**
- **§98 "Cures at a distance," id 189** — centurion's servant, Matt 8 "came
  himself" vs Luke 7 "sent messengers." Strauss: "all which according to
  Matthew the centurion does in his own person, is in Luke done by messengers,"
  rejects the *quod quis per alium facit* harmonization, concludes the accounts
  trace to "a single root."
- **§27 "Retrospect of the genealogies," id 390** — Joseph's paternity nullifies
  the genealogy's Davidic-descent proof if Jesus isn't his son. Haley 1874 p.342
  (verbatim, archive.org `examinationof00hale`) is the paired Mary-lineage
  deeper_learning pd_work.
- **§129 "The Denial of Peter," pp. 658-661, id 462** — Paulus-style
  harmonization of all four gospels' accuser-identity details forces 6-9 total
  denials against the "thrice" prediction. Haley 1874 pp. 424-425 paired
  (verified via search-inside + leaf/page offset in `_page_numbers.json`).
- **§46 "Was Jesus acknowledged by John as the Messiah?", p.224, id 428** —
  John's post-baptismal doubt (Matt 11/Luke 7) is "psychologically impossible"
  after his own baptismal testimony — exact phrase confirmed via search-inside.
- **§104 "Jesus Curses a Barren Fig-Tree," id 451** — Matthew's flat
  "immediately" cannot honestly absorb Mark's overnight gap; Paulus's harmonizing
  read "rests only on an unwarranted transference of Mark's particulars into
  Matthew."
