The TRANSFORM pass turns lean gather notes (`data/harmonization/gather/by_id/<id>.json`) into one machine excerpt file at `data/harmonization/curation/machine/<id>.json`, per `data/harmonization/TRANSFORM_SPEC.md` (the contract — read it in full each run).

**Why:** part of the "commentators' own words" surface (see [[project_harmonization_sweep]]); machine pass feeds a separate sampled auditor.

**How to apply:**
- gather/by_id/<id>.json is often huge (id 13 was 515 lines / >45k tokens). The Read tool caps at 25k tokens and will refuse big offset windows — page it in small chunks (40-80 lines). K&D and MHC notes are the long block-anchored ones.
- `lean`: `reconcile_first` when consensus is apparent_only/...; `discrepancy_first` only for genuine/probable_contradiction. On reconcile_first rows the thin pole is the DISCREPANCY pole → prefer `named_skeptic` (439 model), not empty.
- **Named-skeptic reality bar is strict and easy to get wrong:** name only a skeptic who pressed THIS specific passage-pair. For id 13 (Gen 2 rest vs John 5:17 work), Thomas Paine was a tempting real skeptic but his Age of Reason Genesis-2 objection is the two-creation-accounts / Exodus-vs-Deut-Sabbath-reason argument — NOT this tension. Do not co-opt. The honest fit was Steve Wells / Skeptic's Annotated Bible ("Does God work on the Sabbath?", skepticsannotatedbible.com/contra/god_work.html), the actual upstream source — verified real, states objection as a paraphrase connective.
- **pd_work fallback worked cleanly:** Haley's coverage of THIS exact pair could not be confirmed by search, so per spec I used a row-surfaced harmonizing commentator keyed to the passage (Adam Clarke on John 5:17, which distinguishes rest-from-creating vs unceasing providence). Prefer this over an unverifiable Haley claim.
- **Optional link allowlist = gotquestions.org / carm.org / defendinginerrancy.com only.** Verify the page actually engages the tension before using: for id 13, gotquestions God-rest-seventh-day.html does NOT cite John 5:17, but what-did-God-do-on-the-seventh-day.html does — fetch and confirm, don't trust the title.
- Truncation marker: end mid-sentence excerpts with " …" (U+2026), never a fabricated period. Clarke excerpt ended on a real source period (full sentences); Gill/MHC truncated → " …".
- **SAB list/index pages 404 / return placeholders via WebFetch on bare slugs** (contra/list.html, contra/by_book.html, contra/uz.html). But the per-book verse pages DO render: gen/10.html showed the contradiction icon at v.23 + footnote slug /contra/uz-hul-gether.html cross-ref'd to 1 Chr 1:17. To verify an SAB-sourced row, fetch the VERSE page, not the index.

For excerpts, Gill states the harmonization at the verse ("called the sons of Shem, Ch1 1:17 being his grandsons, which is not unusual in Scripture") and JFB maps the Chronicles names back to Aram+Shem citing Gen 10:23 — both clean reconcile, distinct voices. pd_work anchored to Gill on Gen 10:23 (Haley's specific coverage unconfirmed); no allowlisted link verified (gotquestions sons-of-Aram.html 404) → link omitted, never guessed.
